# QuickClash Windows x64 使用说明

[English](windows_readme.md) | [简体中文](windows_readme_zh_cn.md)

QuickClash 是基于 Mihomo（原 Clash.Meta）内核的独立图形客户端，使用官方预编译内核，不自行开发或修改内核，不提供远程代理节点、节点账号或订阅服务。请自行准备有权使用且来源可信的配置。启用系统代理或 TUN 前，请了解停止网络接管和恢复联网的方法，并遵守适用的法律法规。

当前为未签名的 Windows x64 便携开发版。本机 Windows 的部分使用场景已有验证，干净普通用户环境及剩余授权、系统事件场景仍待核验。`metadata/package_manifest.json` 中的文件摘要用于发现文件变化，不能证明发布者可信，也不能代替签名。

## 快速开始

1. **完整解压 ZIP** 后运行 `bin/quickclash.exe`。保留所有解压目录，包括 `bin/`、`core/`、`geo/`、`metadata/`、`licenses/` 及 Qt 运行资源目录，不要单独移动可执行文件。
2. 阅读首次启动的**使用须知**。点击“我已了解”后在本地保存须知版本，普通升级不重复确认。保存失败仍可进入应用修复，下次启动重新提示；可从**设置 → 关于 → 使用须知**再次查看。
3. 在**订阅**页添加 HTTPS 订阅地址或导入本地 Mihomo YAML 文件。首份有效配置会被选中并自动启动内核，首次使用不会自动开启系统代理或 TUN。下载或校验失败保留原有配置。
4. 在**代理**页选择手动组成员，或使用自动策略组。测速不会改变手动选择。“内核就绪”仅表示本地运行时可用，不代表外网可达或所有远端节点都能使用。
5. 直接使用已就绪的本地 HTTP/SOCKS5 地址，或开启**系统代理**接管遵循 Windows 代理设置的应用；需要 **TUN** 时按下文授权。设置页可调整主题、English/简体中文/跟随系统语言，以及窗口与托盘行为。

## 停止与联网恢复

关闭到托盘后继续转发，最小化保留任务栏入口。从托盘选择**退出**，会停止本应用拥有的内核、清理 TUN 并退出权限服务进程，同时恢复仍由本应用持有的系统代理设置；其他软件后来修改的设置会保留。退出保留系统代理和 TUN 开关偏好，服务注册与目录授权也会保留。

**GUI 崩溃或被强制终止后，系统代理可能仍指向已停止的本地端口并影响联网，普通与服务模式均有此限制。** 请重新打开 QuickClash，让它核对并恢复已保存的代理租约；该恢复可在无外网时启动。重开后可能恢复已保存的系统代理/TUN 意图，如需保持关闭，请明确关闭对应开关。无法重开或恢复失败时，在 **Windows 设置 → 网络和 Internet → 代理**中检查，仅处理能确认属于 QuickClash 本地地址的手动代理项，保留其他软件后来修改的设置。服务仍在运行也不保证 GUI 异常后即时恢复系统代理。

端口冲突时，在**设置 → 网络**中手动修改，或使用**使用可用端口…**填入草稿，再通过**应用网络设置…**确认。应用不会静默修改已保存端口；内核运行时应用变更可能中断连接。

## TUN、服务授权与便携更新

TUN 需要权限服务，普通系统代理不需要。首次开启 TUN 时，请求 Windows 管理员确认，从本包安装服务或授权当前目录；确认后继续开启 TUN，取消则保持普通模式。GUI 保持普通用户权限；服务安装使用程序内置的固定动作，不依赖 PowerShell。

服务信任已授权位置下的 `bin/quickclash.exe`，并将请求绑定到活动控制台会话及进程身份。信任同时覆盖目录内的服务、运行库和后续更新，不证明文件内容真实可信。请使用可信来源的包，并放在 Everyone/Anonymous 不可写的目录。移动或改名便携目录后需要重新授权。当前支持范围为活动控制台单用户，远程桌面与跨用户操作尚未验证。

服务按需启动，QuickClash 真正退出后服务进程也会退出。下次手动启动或登录自启时，应用按上次保存的开关偏好恢复：上次开启 TUN 则尝试恢复，上次明确关闭则保持关闭；同一已授权目录无需再次 UAC。仅保留服务注册不会在开机时独自开启 TUN。QuickClash 会避让同名网卡；另一 VPN/TUN 已接管默认路由时，需要先关闭对方。WSL/Hyper-V 等局部路由网卡可以共存。清理无法确认时会保留恢复记录并阻止另一会话，请勿删除无关网卡。

GUI 与服务须来自同一包。替换已授权目录内的文件前，正常退出 QuickClash 并等待 `quickclash_service.exe` 退出，再更新完整包并重启；无需先关闭 TUN 开关，同一授权目录更新无需重新授权目录。旧版服务仍驻留时，手动停止 `QuickClashService` 并确认进程退出；新服务会将已授权旧自动启动注册迁移为按需启动。便携目录是程序、服务、内核和随包 Geo 的来源；`%ProgramData%/QuickClash` 保存受保护授权、私有会话和清理数据。

删除或移动已注册服务的安装目录前，先在管理员终端进入解压包根目录，执行：

```powershell
.\bin\quickclash.exe --service-setup uninstall
```

该操作移除服务注册与目录授权，保留程序文件和用户数据。

## 数据、内核、资源与已知限制

通过**设置 → 数据与诊断 → 打开数据目录**查看实际用户数据位置，重新解压程序不会删除这些数据。订阅地址、请求头和测试目标使用当前用户 Windows DPAPI；节点凭据、草稿、备份和恢复归档可能包含明文秘密，请妥善保管。复制凭据文件到另一 Windows 账户无法解密。

随包 `core/mihomo.exe` 和 Geo 文件按冻结元数据核验，缺失或不符时阻止使用，不会静默下载。可通过**设置 → 内核与资源**下载/修复兼容内核，以及下载、应用和回退 Geo。内核下载后须单独确认应用；Geo 计划下载只生成待确认快照，手动点击**更新 Geo 数据库…**则先确认，再下载、校验并一起应用两库。仅支持下载客户端兼容清单内的内核，不能任意升级到上游版本。应用资源可能重启内核并中断连接，请保留完整包以便恢复。

自建策略组属于对应订阅/配置条目。更新该条目或修改其地址会保留自建组；删除条目会移除所属组，历史回退恢复对应版本的定义。缺少依赖或名称冲突会拒绝更新并保留旧数据。已有更换订阅后疑似丢失的反馈仍未复现或解释。

配置备份可能含明文凭据，目前没有密码加密。启用的配置专属 `RULE-SET` 若依赖离线快照中不存在的运行时规则提供者，两种备份范围都会拒绝整份导出。重要原始配置请另行保留，不要假定所有运行时提供者配置都能离线备份。

配置或资源出错时，先阅读界面错误，正常退出并核对完整解压目录后重试。损坏或较新 schema 的用户数据会保留，可能需要明确执行恢复；不要把删除数据目录作为首个排错步骤。
