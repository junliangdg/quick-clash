# QuickClash for Windows x64

解压完整 ZIP 后运行 `bin/quickclash.exe`。请保留 bin、core、geo、metadata 与 licenses 目录，不要单独移动可执行文件。

在订阅页导入 Clash Meta (mihomo) YAML 文件或 HTTPS 订阅地址。首份有效配置会启动随包内核；随后可在代理页选择节点，并在首页开启当前用户的系统代理。首次导入不会自动开启系统代理或 TUN。订阅地址必须是最终 HTTPS 地址，目前不跟随重定向。

关闭窗口可保留托盘与后台转发；从托盘选择退出会停止本应用的内核，并恢复仍由本应用拥有的系统代理设置。设置页面可调整主题、窗口和托盘行为，语言跟随系统。

core/mihomo.exe 和 Geo 数据来自随包锁定版本，缺失或摘要不符会阻止相关配置；客户端不会自动下载补齐。版本、来源和文件摘要见 metadata，第三方许可见 licenses。当前便携包未签名。

TUN 需要权限服务。需要使用时，以管理员身份在 PowerShell 7.2 或更新版本运行 `./install_service_windows.ps1 -PackageDirectory .`，核对提示后安装；普通系统代理使用不要求安装服务。卸载服务使用相同命令并加 -Uninstall，已安装文件和用户数据会保留。不要在其他代理程序运行时安装或切换 TUN。

设置中的“打开数据目录”可用于查看本地诊断。配置或资源错误会显示在界面中；先退出应用并核对完整解压的目录，再重新导入有效配置。重新解压程序不会自动删除用户数据。
