# 发布清单与能力验证

此清单用于发布前核对当前版本、实际声明的平台与功能；不是日常开发流程门。勾选须有对应版本、验证范围与可核对的结果，未运行、失败或证据失效不得标通过。具体结果和未关闭风险以 [TASKS](TASKS.md) 为入口，复杂过程可引用 DEVLOG、CI 运行或重要报告。

## 发布前检查

- [ ] 明确构建版本、支持的平台、发行范围和已知限制；在目标环境验证安装/启动及必要依赖。
- [ ] 代表性订阅导入、配置应用、组/节点选择、系统代理和实际转发链路按声明范围运行；失败或中断不破坏最后可用配置。
- [ ] 声明支持的系统代理、TUN、权限服务和更新具备适用的失败、退出、恢复和清理验证；不宣称未经验证的能力。
- [ ] 秘密不进入日志或发布物；官方 Mihomo 资产来源、版本和摘要可核验，许可、对应源码材料及发布包内容符合发行要求。
- [ ] 按风险复核关键回归、可访问性、资源及代表性持续运行；记录未覆盖范围、阻断缺陷和可操作的恢复说明。
- [ ] 对外说明未验证的平台、功能和已知问题；历史结果只在版本和范围仍适用时复用。

## 2026-11-07 Windows 首版就绪度核对

结论：现有证据支持本机自用及小范围日常试用的功能基础，可进入首版发布收尾；尚不足以将当前工作区或历史包认定为面向普通用户的稳定日常版。此处仅复核记录、构建缓存和已有日志，本轮产品构建/测试 NotRun，发布前检查保持未勾选。

- 最新页面、订阅及资源更新改动已有 Windows 定向构建/测试记录；已核对 11-07 资源更新最终 CTest 4/4 和无障碍/订阅复验 4/4 的原始日志，不将多轮局部结果合并为当前版本完整回归。真实订阅、系统代理、TUN 转发及受控恢复沿用各自注明版本的本机证据。
- 当前 HEAD 为 `6002617`，仍有未提交实现；`build/dev` 与 `build/traffic_continuity` 的实际 Qt 为 6.12.0，发行矩阵与 Windows CI 为 6.9.0。首版须固定源码和实际随包工具链，在该版本验证最新改动；11-05 的 Qt 6.9 完整回归不能代替当前版本验收。最新改动尚无本轮生成的发行包，既有 `continuous` 核对结果仅适用其历史提交；本轮未确认远端最新包状态。
- 发布收尾按实际范围选择：生成 `BUILD_TESTING=OFF` 的 Windows x64 Release 包并执行候选版本完整验证；补干净普通用户环境、系统重启/换网/唤醒，以及所声明 TUN/权限服务的首次授权、取消和失败清理路径；补代表性真实 GUI 加服务的持续使用观察、随包许可/对应源码材料及恢复说明。相关未验与已知风险见 [TASKS](TASKS.md)。
- 首版可限定 Windows x64 便携包、活动控制台单用户及手动换包；安装器、签名、应用自动更新、Linux/macOS 和未声明支持的跨用户专项可后续推进，未签名状态及限制须明确。GUI 强杀后代理须重启应用恢复、疑似策略组丢失尚未解释和离线 `RULE-SET` 备份限制应保留在候选版风险说明中；不凭缩小范围将实际故障记为通过。
