## 3. 失效与重跑

源码、依赖、内核、schema、配置策略或支持平台变化时，依据影响将相关 Pass 标 Stale，撤销对应阶段检查项，旧报告保留。行为变化导致验收失败则标 Fail；补救完成重跑后再标 Pass。G2 Pass 只表示记录版本的 Windows MVP，不自动证明三平台/稳定版。P3/P4/P5 汇总报告必须逐项注明哪些旧验收仍有效、哪些已重跑；新平台需新增对应报告，不把 Windows 记录当作其他平台结果。

2026-10-25用户回归：[代理/内存修复](reports/20261025_proxy_memory_fixes.md)已完成实现和7/7受影响回归；分组按订阅顺序、默认出口/查看组区分、首页摘要及客户端/内核独立三指标已接入。公开56节点/12,001规则GUI订阅更新约13秒定向测量：最终包有变峰76,451,840B专用工作集、180,097,024B工作集、228,347,904B私有提交，未变保留内核、有变确认应用；该单场景满足100MB，不等同全部私有订阅或长稳通过。
旧出口UI及旧二进制资源结论对本次变更Stale，旧Ready首页值不用于证明更新峰值。G2/G3仍NotRun，MVP-05/06仅保留历史未受影响范围；本轮runtime使用注入代理，没有新增真实WinINet/TUN/服务或干净机结果。
