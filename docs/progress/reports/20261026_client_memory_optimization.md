## 2026-11-05 日常内存分层分析与实施

本轮优先日常稳态、重复数据和页面生命周期；用户反馈订阅更新暴涨只在部分本地环境复现，该问题保留为低优先级独立调查，不把历史字体线索推断成通用根因。结论是：权限服务的完整 JSON 重放缓存存在明显放大风险，GUI 仍有可取消的常驻展开与编辑器；现有 500 节点普通业务短测尚未证实客户端整体明显下降。以下区分当前实现、已实施改动、实测及后续工作。

### 内核管理与权限服务

- Mihomo 继续使用已冻结的官方 v1.19.33 预编译资产。其规则、连接、健康检查和实际流量所需内存单列；本轮不改内核、不削减用户配置或改变健康检查行为。客户端 worker 是同进程线程，服务模式还有独立权限服务，不能只看窗口或把服务移出客户端统计。
- 已有 `EngineSession` 对组刷新做在途合并；代理页需求下约每五秒刷新，服务状态/可见流约一秒轮询，业务事件另可触发刷新。连接、规则、日志等按页面需求开启，取消/epoch/请求代次阻止旧结果复活。不能为省内存停掉必要控制、恢复及配置确认。
- **本轮修复**：[ServiceProtocol](../../../src/infra/core/service_protocol.cpp) 原来按最近32项保留展开的 `QJsonObject`；每轮独立解析的节点及 history 响应即使内容相似也会常驻。现改为紧凑 JSON 字节，仅重放时解析，增加 **32项与累计4 MiB双限额**。单个超限结果正常发送但不缓存，旧 ID 仍拒绝，不能重新执行已完成的修改；缓存内同 ID 异报文继续断开。现有40在途上限保持。
- **本轮修复**：服务的[选择校验目录](../../../src/infra/core/proxy_catalog.h)仅保留代理名以及 Selector 的 type/all，不再为了选择与测速校验持有全部 history/extra；返回客户端的 API 数据保持完整。控制 API 成功解析后、通知业务或开始后续请求前释放原始传输字节，减少短时重叠；字节限额、超时和失败留旧不变。
- 服务端缓存改动已构建、单测和组件对照；**本轮未安装/启动实际 SYSTEM 服务、未开启 TUN**。服务模式完整进程树、实际轮询混合及恢复矩阵仍 NotRun，组件数字不能直接套到日常整机收益。

### 业务、数据发布与所有权

- `DesktopRuntime` 仍需保留配置身份、代理组及选择状态，支持托盘、选择确认与恢复；隐藏时不能清掉这些业务权威数据。`groups_`、`configuredGroups_`、发布快照等 JSON 句柄存在隐式共享，不能把每个字段计成独立全量副本。
- 已有 latest mailbox 每通道只保留最新待处理值，控制/操作结果可靠投递；最后需求释放时清 worker 页面数据、发布基线、GUI模型和迟到请求。日志现源码预算为页面2000条/4 MiB、App诊断100条/512 KiB、服务200条/512 KiB，任一先到淘汰；旧表“页面1000条”不是当前上限。页面暂停可有界保留，离页释放 Core 日志。
- 测速每节点最多8个目标观测，变化或过期才重建投影；`features.delayTimes` 兼容投影仍保留，服务32/直连6并发、队列与取消机制已有。下一步应测有历史观测的真实负载，判断兼容投影及完整控制快照的展开成本，再决定是否精简契约。
- **本轮修复**：[UiState](../../../src/presentation/ui_state.h) 的节点、组、测速和目标详情改用共享 JSON 存储；只在页面/显式兼容 getter 读取时展开 QVariant。单个代理状态直接读 JSON，避免常驻另一份完整 QVariant 树，保留计数、通知、目标匹配及循环保护。代理页仍持有当前页 JS 展示数据，并非整个应用零拷贝。
- 配置事务、YAML解析/校验、原文与有效配置预览仍可能短时并存；现有单事务、provider暂存和有界读取降低无界风险，但不能据此推断解析峰值已低。本轮没有重做解析器或改变成功/失败保留语义。

### 客户端界面与页面

Qt/QML、字体、图形驱动和分配器构成可见窗口的基础成本；进程三指标不能精确拆出每一项，需按调用栈或图形工具进一步归因。继续保持默认 RHI/GPU，不使用主动 GC、裁剪工作集或软件渲染制造下降。页面对象销毁与 OS 立即返页是不同事实，不能凭退出页面后仍有驻留判断泄漏。

| 首页 | 已有部分控件/弹窗惰性化、当前代理状态按项读取；本轮进一步减少 UiState 完整展开 | Qt/字体/图形基线；常规业务下新增收益较小 |
| 代理 | 可视节点委托有界，页面缓存索引；本轮自定义策略组编辑器按打开创建、关闭后销毁 | 所有组成员的 JS 筛选数组、组/节点完整页投影仍在；可按组和视口逐步下推 |
