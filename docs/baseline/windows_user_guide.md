# QuickClash Windows 本地验证版

QuickClash 是基于 Mihomo（原 Clash.Meta）内核的独立图形客户端，使用随包官方预编译内核，不自行开发或修改内核，不提供远程代理节点、节点账号或订阅服务；请自行准备有权使用且来源可信的配置。启用系统代理/TUN前应了解下文的停止与恢复方法，并遵守适用的法律法规。QuickClash 适用 GPL-3.0-only，第三方组件分别适用自己的许可，文件见发行包 `licenses/`。

首次启动会显示“使用须知”，点击“我已了解”后本地保存须知版本；已有设置缺少记录也会提示，普通升级不重复。须知有实质变化才更新版本。保存失败保留旧设置、允许进入修复，下次启动重新提示；“设置→关于→使用须知”可随时重看同一正文。登录隐藏启动遇到待确认须知时会先打开主窗口。

添加HTTPS订阅时，名称留空会自动使用服务返回的订阅标题或配置文件名；没有有效名称则使用“新配置”。手填名称优先，后续更新和替换来源保留现有名称。订阅卡片“管理”中的单个地址框默认隐藏，支持显示、复制和修改；点击“修改”后直接编辑该地址，再点击“保存并更新”，本地配置也可从此添加地址。未保存即关闭、切页或退出时可保存、放弃或继续编辑；保存过程中请求关闭或退出会等待操作结果。下载或校验失败保留旧地址与配置，并保留输入供重试；地址保存成功但应用失败会分别提示，卡片提供重试应用。关闭弹窗、离开页面或隐藏窗口后地址恢复隐藏。订阅地址可能含访问凭据，复制后保留在系统剪贴板，请按需保管。

节点测速数值在代理页、仪表盘和规则出口下拉中采用相同字号、字重与配色；下拉将延迟置于右侧，长节点名省略时仍保留完整延迟。低于300ms为绿、300—799ms为黄、至少800ms及不可用/超时为红，未测速/过期为弱化色。

代理页、仪表盘出口和出口下拉共用内核确认的组/节点状态及延迟。内核自动健康检查有结果后无需手动测速即可显示；可见时约5秒刷新读取，读取本身不触发测速。下拉中的自动组显示其当前节点及对应探测目标的延迟，负载均衡不显示唯一出口；选择仍按原始成员执行。延迟来源和时间在出口区域及选项提示中可见，不同探测地址的结果分别保存；超过10分钟标记过期，内核失败不会显示0ms。

在组内手动测速使用该组探测地址，仪表盘“测试当前节点”按当前策略沿嵌套组解析相同目标；没有组探测地址时使用设置中的全局HTTPS地址。组标题的“测延迟”默认递归包含子组，按各分支目标测速，优先安排被点击组的直接节点。只有子组的组也可使用该按钮。单批次同一节点和相同地址只测一次，相关组、代理页和仪表盘共享状态与结果；不同地址分别测速及显示，再次点击则重新测量。进度和取消显示在发起组；该组折叠或隐藏时页面仍提供取消入口。修改全局地址不会使其他地址的结果过期。测速完成后刷新核心当前出口，自动组是否切换仍受核心容差和策略影响，不保证立即改选最低数值节点；取消后核心已发请求可能短暂继续。

仪表盘按“当前订阅、实时流量、代理与网络、网络工具、运行概况”排列。内容超出窗口时，可拖动内容、使用鼠标滚轮或滚动条上下浏览；普通点击仍可操作按钮和下拉框。订阅可直接切换和更新；主策略手动组可切换成员，自动组以内核确认结果为准。系统代理与TUN都关闭时，已就绪内核的本地代理端口仍可使用。

网络工具的IP对照需点击查询，IPv4和IPv6分开保留；左侧不使用应用代理，仍可能受TUN或其他VPN影响，右侧经当前代理入口并遵循规则。显示IP、服务商、组织、位置及来源/时间，可复制或隐藏；位置来自IP数据库，两侧相同不代表故障。查询会请求IP.SB，不会自动发送。Google、YouTube、GitHub支持单项/全部测试和取消，结果是HTTPS入口可达性与总耗时，不代表带宽或解锁。

卡片标题与常用操作配有本地图标，网站按钮同时显示站点图标和名称。延迟小于300ms显示绿色、300—799ms黄色、至少800ms及失败红色，未测或过期弱化；测试结果保留明确状态文字，时间及来源单独显示。图标和颜色不会触发额外请求。

运行概况默认并列展示内核名称与版本、客户端内存、内核内存及本次运行时长；宽屏四项一行，中等宽度两列，窄窗纵排。首页可见时约每5秒采样，离页或隐藏后停止；详情默认收起，展开可看客户端合计与内核的完整内存指标、独立服务/校验器、运行方式及系统架构，不重复列出QuickClash进程内存。内核就绪时显示实际本地代理地址，可复制供HTTP/SOCKS5应用填写；未就绪不可复制，不显示已保存端口为可用。IP区、网站区及详情显示设置会记住；流量曲线固定显示，旧版收起设置不再影响展示。本次内核运行累计直接使用内核返回值，缺失不估算。

端口被占用时，提示会列出具体 TCP 端口；Windows 拒绝绑定会单独说明，不猜测占用进程。设置→网络可手动修改，或点击“使用可用端口…”查看候选，确认后仅填入草稿，再通过运行配置组末尾的“应用网络设置…”提交。取消不会改变已保存设置；候选仍可能被其他程序抢占，应用时会重新检查。已知监听冲突会暂停后台反复启动，修复后点击“重试”。运行中的端口变更会中断已有连接；失败通过原配置事务恢复，系统代理只迁移本应用仍拥有的租约。

TUN 使用服务保存的安装专属名称，如 QuickClash-a1b2c3d4；遇到未知同名网卡会自动换名，保留对方网卡。另一 VPN/TUN 正在使用默认路由时，会提示先关闭对应模式，QuickClash 不会替你关闭它。普通局部路由的虚拟网卡不会仅因存在而阻止开启。清理无法确认时显示 Uncertain 并阻止另一会话；先核对服务日志及记录的网卡，不要按名称批量删除虚拟网卡。GUI 与服务须来自同一包；旧注册迁移需一次管理员确认；已注册同目录服务版本不一致时直接重启复用。

自动换名只处理网卡名称冲突，不等于可以同时开启两个全局 TUN。Windows 可以有多张虚拟网卡，但默认路由只会选中一个；另一 VPN/TUN 已接管默认路由时，QuickClash 会提示冲突并要求先关闭对方，不会通过降低路由 metric 抢走它的流量。WSL/Hyper-V 等只使用局部路由的虚拟网卡可以共存。

首次开启TUN时请求一次Windows管理员确认，将服务直接注册到当前便携目录。GUI保持普通权限，取消保持普通模式。之后重开应用沿用保存的TUN意图，已注册服务停止后也可直接启动，无需重复UAC。服务随系统启动，但只有活动用户打开应用并恢复会话后才开启TUN。原生固定动作不依赖PowerShell。可使用 bin\quickclash.exe --service-setup validate --client-root <bin绝对路径> 检查布局。

程序、服务、内核和随包Geo共用便携文件，不再复制到Program Files。同目录升级无需重新授权；替换服务文件前先停止QuickClashService，再更新完整包并重启。跨目录换包或移动目录后，下一次开启TUN会请求UAC修复路径。首次从旧版迁移也需一次确认，成功后清理可识别的旧载荷。

服务按命名管道对端PID核验最终镜像路径，要求恰好等于受信目录下的quickclash.exe，并绑定SID、活动控制台会话、PID与进程创建时间；受信目录保存在%ProgramData%/QuickClash/trusted_client_root.json（SYSTEM与管理员可写）。移动或改名目录后再次开启TUN，应用会请求一次管理员确认重新授权。安装动作拒绝盘符根、ProgramData/Public/SystemRoot子树、Program Files根、重解析点以及Everyone/Anonymous可写目录。信任的是授权位置，不证明镜像内容；未签名本地包须先审阅来源。

卸载服务需在管理员终端运行 bin\quickclash.exe --service-setup uninstall，删除服务注册与目录授权，保留便携程序及用户数据。删除/移动程序前应先卸载，或保留目录待下次修复注册。

服务握手不兼容、身份错误或另一客户端占用时会拒绝权限操作。断线会停止服务拥有的内核；当前服务未核验跨用户WinINet恢复能力，系统代理仍由当前用户租约恢复，GUI被强杀后可能需要下次启动或手工处理。服务不因驻留就保证系统代理即时恢复。真实TUN和普通用户环境以任务验收记录为准。

设置→网络同时展示已保存配置与当前生效配置。可一次调整模式、代理/控制器端口和DNS模式，再确认应用；运行中会短暂重启并断开连接，失败时尝试恢复原配置。确认窗口打开后若切换了配置或运行会话，需要重新确认。内核停止时只保存设置，不显示为已生效。系统代理和TUN开关显示实际启用状态，所请求的状态另列；授权失败不会显示为已开启。

DNS支持内核内部fake-ip、redir-host或沿用订阅模式。解析器策略、过滤和缓存设置按受支持字段保留；fake-ip子网须位于198.18.0.0/15内，前缀15—30，bootstrap解析器须为IP地址，回环/未指定地址及localhost会被拒绝。设置页可清除DNS缓存，并显示清理中、成功或失败；停止或更换会话后清除旧结果。普通模式不开放订阅中的DNS监听，也不修改系统DNS；外部DNS接管随TUN单独验收。

## 界面与主题

当前开发版采用极简桌面工具风，八个页面统一使用中性灰面板、蓝紫强调、小圆角和共享表单控件。右上角或设置→通用→外观与语言可选择浅色、深色、跟随系统；默认跟随系统，选择会保存。切换主题保留当前页和未保存表单内容，不自动应用端口或发起测试。

登录启动、系统代理、TUN及界面卸载使用滑动开关；登录隐藏到托盘使用附属复选框，登录启动开启后才可修改。

设置页固定分为“通用、网络、内核与资源、数据与诊断、关于”。所有窗口宽度都使用同一条页签；窄窗通过两端按钮或拖动横向查看分类，滚动本身不切分类。键盘方向键及Home/End只移动焦点，Enter/Space切换分类。窄窗标题行的“其他”可打开连接、规则、日志、测试。

网络模式、两端口与DNS共用一份草稿和组末尾的应用入口，节点测速目标在自己的分组中单独保存。切换分类、离开设置、缩放窗口或托盘卸载界面均保留本次运行中的草稿；应用失败也保留输入。配置或已保存值发生变化时，可重新载入保存值，或保留输入并重新确认。真正退出时会提示是否放弃未提交输入；退出后不恢复临时草稿。内核/Geo的回退及随包恢复入口位于各组“高级恢复”，备份、清理、诊断和只读恢复集中在“数据与诊断”。

设置页不再提供“原型数据”开关。合成数据回放仅供开发测试构建通过命令行显式启用，日常使用显示实际数据；缺少数据时显示空状态。

仪表盘将当前订阅与实时流量并排显示，窄窗自动上下排列；代理模式和系统代理/TUN位于控制条，当前出口独立显示。流量图约每秒更新，固定60点表示最近60秒，上下行分别使用紫色/琥珀色，共用纵轴；内核就绪时，切页、最小化、关闭到托盘及卸载界面仍连续记录，返回立即显示已有曲线。不可见时不绘图，后台只保留共享流量需求；确认停止后速率归零，近期历史随时间滚动，重启和状态不确定时留下空档。历史仅保存在应用内存，关闭应用后不保留；累计仍只显示本次内核运行的官方数据。最小化不会因低内存选项而卸载界面或中断该记录。
零流量和大幅升降仍连续连线；较小流量在同一纵轴下会靠近底部。真实缺采样保留空档，恢复后的首个有效点会立即显示。
图表纵轴上限显示在绘图区左上方，按数值自动切换KiB/s、MiB/s或GiB/s，避免大数值遮住曲线。

仪表盘不提供“收起曲线”“查看代理”“详细测试”按钮；完整代理页和测试页从应用导航进入，窄窗测试页从设置的“其他”进入。

当前订阅卡片通过下拉框显示所选订阅，不另显示“已应用”等状态角标；运行阶段、就绪及完整错误仍在页头状态提示中查看。

宽度至少1000时默认显示完整侧栏，可用品牌旁的独立面板箭头收起；600—999默认显示图标栏，可用同一按钮展开名称。灵猫Q标志用于品牌展示，收展按钮有单独的提示和键盘焦点。小于600时使用仪表盘、代理、订阅、设置四个底部入口。连接、规则、日志和测试从窄窗设置的“其他”进入，并可从页头返回。最小窗口360×480逻辑像素。程序/窗口/任务栏使用彩色灵猫Q，EXE内含多尺寸图标；托盘使用单色猫形，跟随系统任务栏明暗。

本轮Windows增量构建与10项相关测试通过；双主题、原生125% DPI及360/800/1000/1200宽度已核对。开发场景10秒资源短测专用工作集峰值115.45MB；客户端持续追求小内存占用，保持Qt Quick默认RHI/GPU，不设固定MB门槛。资源按同环境基线、有界缓存与需求释放评价；详见[实施与验证](../progress/reports/20261027_unified_visual_implementation.md)。开发版更新不表示既有dist包已重新发布。

TUIC支持token或UUID/密码两种认证，二者不可混填；节点卡显示其原生UDP能力。负载均衡组支持一致性哈希、轮询和粘性会话三种策略，由内核选择每个连接的出口，因此组内没有手选开关或统一当前节点。TCP/WS/gRPC、Reality及其他已声明协议仍按随包字段清单校验；未知扩展会给出诊断，官方加载成功不能保证远端节点可用。

## 节点查找、托盘与日常提醒

代理页顶部可搜索节点或策略组名称，不区分大小写；匹配策略组名称会显示该组全部成员。清空搜索恢复原有组展开状态；“定位当前节点”会清空搜索、展开对应组并聚焦当前节点，不会切换节点。每个展开的组也有定位入口，负载均衡组没有统一当前节点。搜索和展开状态只在本次运行中按订阅记忆。

托盘菜单显示运行状态、当前订阅和已确认主出口，并可切换规则/全局/直连模式。模式仍通过原有设置流程保存应用，运行中可能短暂重启连接；提交期间不可重复操作。系统代理和TUN的勾选表示实际生效，已请求但未生效会单独写明；托盘提示不代表所有连接都使用同一节点。

连接详情的“生成规则”把精确域名或单个目标IP填入自定义规则编辑器，默认当前订阅专属范围和直连目标。先检查匹配值及目标，加入草稿后再点击“确定”保存应用；取消不改变配置。已有未完成规则草稿时会提示先处理，不覆盖原输入。连接已结束、数据过期或配置不可写时不生成规则。

后台托盘提醒覆盖订阅更新失败、流量不足/耗尽、临近到期/已到期，以及代理冲突、TUN清理待确认和自动恢复耗尽。同一问题会去重，恢复后再次出现或严重程度升级才重新提醒；系统通知不展示订阅地址和认证信息。点击提醒打开对应的设置或订阅页，Windows关闭通知或托盘不可用时仍可在应用内查看状态。到期和流量提醒依赖订阅已提供并发布的数据，不会为此额外查询订阅。

这些入口的当前验证状态见[任务台账](../progress/TASKS.md)；代码存在不等于真实换网、睡眠唤醒或TUN转发/清理已验收。

## Qt 6.8 字体与前台内存

代理页可独立展开多个组，同一配置在切页后保留全部收起状态。大组按可视行创建节点卡，方向键移动，Home/End定位首尾；自动组由内核选择。节点或组测速使用组探测目标，未配置时使用设置中的独立HTTPS目标，可能消耗节点流量；直连模式最多同时测试6项、服务模式最多32项，单批最多500个节点与目标组合。取消停止排队并忽略迟到结果，已发出的内核探测可能短暂继续；离开代理相关页面后停止队列。结果10分钟后过期；手动目标改变只使旧目标的手动记录过期，配置切换清除会话结果。

当前开发版`build/dev/quickclash.exe`使用概念预览的导航符号（▦/◎/▤/⇄/≡/›_/⌁/⚙），保留宿主统一传递字体配置。运行状态在页头右上角显示，完整错误可悬浮或键盘聚焦状态指示查看，页面不重复插入错误行；主题切换位于设置的外观区域；当前订阅和流量卡使用同一套图标及文字层级。订阅/节点文字保持原样，仍支持系统字体回退。更新后数百MB字体驻留的真实实例已确认，但公开夹具未复现，不能宣称本构建已修复；[实测与限制](../progress/reports/20261026_subscription_memory_investigation.md)。

正常启动使用Qt Quick场景图，由Qt的图形抽象层选择平台后端；客户端没有将GDI字体后端或软件绘制设为默认。Windows本机字体后端对照只用于历史诊断，不作为跨平台产品的低内存使用方案，相关启动建议已撤下。Qt Quick的软件适配本身也是Qt提供的跨平台能力，但其资源/CPU与效果须单独验证，不由一组Windows结果决定产品默认。

内存优化继续围绕Qt支持的对象/模型生命周期、文字布局与字形缓存、可见页绘制资源开展，在默认Qt Quick路径核对真实异常。此前矢量版资源数字对恢复版Stale，不作为当前版占用承诺；完整历史记录见调查报告。不要删除系统字体缓存、反复裁剪工作集或修改节点原名作为日常解决办法。

运行 bin/quickclash.exe，默认内核来自随包 core/mihomo.exe，版本和摘要见 metadata/release_matrix.json。启动无需开发 Qt PATH，不自动下载内核；不要移动其中单个 exe。显式更新可选择经过兼容清单验证的受管版本。

随包内核缺失或摘要不符时会显示CoreIntegrityFailed，程序不会改用开发目录中的内核。保留用户数据，重新解压完整且摘要正确的同版本包后重开；UI仍可查看错误、修改端口、打开日志/数据目录，内核恢复前导入校验不会成功。

Geo数据位于geo/，须与整个目录一起保留。程序在导入和启动时核对固定摘要，资源缺失或损坏会阻止相关配置，不会联网自动补下载。

1. 在订阅页导入本地Mihomo YAML，或粘贴标准HTTPS订阅地址。程序自动请求Mihomo格式并识别内容；无需手工添加格式参数。Base64/分享链接尚不转换，URL适配不代表配置中所有协议均已接入。地址和请求头以当前用户DPAPI加密保存。下载默认直连，可选“运行中的代理”或“自动”；自动仅在直连网络失败且内核就绪时经代理重试一次，认证/证书/内容错误不回退。首次未运行内核时使用直连或本地导入。
2. 首份有效配置自动选中，后台自动运行随包Mihomo；之后点击订阅卡片切换配置，代理页随之显示该订阅的分组。导入成功与内核就绪分别显示；首次不会自动开启系统代理或TUN。无需管理内核列表或手动启动。
3. 首页订阅卡只显示订阅与总体预览；运行阶段/正常或异常指示显示在页头右上角，完整错误通过状态指示的悬浮或聚焦提示查看；版本和运行时间在“运行概况”区域显示，不重复就绪标识。代理页按订阅原顺序显示代理组卡片，点击展开/收起查看该组成员；选择select组成员才改变该组的出口。规则模式依据MATCH默认策略，全局依据GLOBAL，直连显示DIRECT；不同规则和已有连接可能使用其他节点。自动组由Mihomo选择成员，可见时约5秒刷新当前值。首页切换规则/全局/直连模式；运行中切换配置、模式或端口会受控重启，失败尝试恢复原确认版本。
4. 首页“系统代理”开启当前用户 WinINet LAN 的 HTTP/HTTPS 代理；客户端就绪及节点恢复后才写入。它不覆盖 WinHTTP、RAS、其他用户或应用自己的代理配置。
5. 测试页填写1—8个HTTPS网站，每行一个；选择当前代理、直连或系统默认路径，输入区显示数量和上限。请求串行执行GET，每项最多3次HTTPS跳转，整条链12秒/64KiB上限，无Cookie/自动认证，不允许降级HTTP。当前代理失败不回退直连；直连仍受TUN/系统路由影响。结果及最近32项历史显示路径、状态、耗时和时间，可展开模式/组选择与最终来源；配置/节点/网络变化标过期，离页取消队列。规则可能选择DIRECT，因此入口可达不代表指定远端节点转发成功；可选IP查询未配置时隐藏。
6. 关闭窗口可保留托盘和内核；关闭系统代理仅释放代理租约，后台内核继续提供本地转发。退出才清理本应用会话/Job并恢复仍拥有的设置。发现其他程序更改代理时保留外部值并提示冲突。

首页“运行概况”默认分别显示QuickClash客户端和Mihomo内核的专用工作集；提示说明口径，详情列出完整三项。专用工作集是当前驻留且不共享的物理内存；工作集包含共享驻留页；私有提交是进程承诺使用的私有内存，不能当作当前物理占用。三项均使用十进制MB；客户端包含运行中的必要辅助服务，内核单列，客户端与内核分别报告，不把合计值当客户端读数；不设固定MB门槛。缺失/过期数据以破折号显示，部分统计明确提示。

### 可选Qt Quick软件渲染

在托盘选择退出，确认旧客户端完全结束后，可以在PowerShell中启动本次软件渲染模式：

    & D:/repos/quick-clash/build/dev/quickclash.exe --software-rendering

该参数通过Qt API选择Qt Quick跨平台CPU场景图，继续使用相同QML界面、符号和Qt字体回退；不设置GDI、不更改系统环境或订阅设置。它可以减少部分渲染资源开销，但无法保证解决字体文件驻留或业务内存增长。软件模式的滚动/动画CPU成本和显示效果需按实际机器验证；本机短测不代表其他平台原生验收。恢复默认GPU模式只需完全退出，再不带该参数启动；已有实例运行时，新命令仅激活旧窗口，不改变它的渲染后端。

### 开发者可选：只读附着内存短测

在仓库根目录使用PowerShell 7.2+运行[附着脚本](../../bench/attach_memory_windows.ps1)。通过任务管理器确认客户端、必要辅助服务及内核PID后，分别传入客户端列表与内核列表；输出目录必须尚不存在。例如本机确认的客户端PID为1234、辅助服务2345、内核3456时：

    & ./bench/attach_memory_windows.ps1 -ClientPid @(1234,2345) -CorePid 3456 -OutputDirectory .local/memory_user_update -Seconds 10

上述数组参数示例在PowerShell 7.2+交互终端直接调用脚本；不要将示例PID照搬为真实目标。脚本只查询，不启动/退出/裁剪进程，不读取命令行或订阅；普通权限失败即报告未知/失败，不需提升权限。可在采样期间自行正常操作订阅更新。输出每PID三指标、角色和采样轮次，不自动证明来源版本或进程组完整；正式比较需按采样轮次将所有必要客户端/服务相加，并保持环境与负载一致，内核另列，不相加各PID不同轮的峰值。内核更新重启后旧PID样本不完整，需重新确认PID再采样；新代码未构建时，旧实例读数不能当新代码验收。

新添加的订阅默认每6小时自动更新，选中条目有变化时自动应用；在订阅条目选择手动/每小时/6小时/12小时/每天，以及“自动更新后应用当前订阅”。旧条目保持原来的手动策略，需要自行开启。更新时间以本地时间显示；失败有状态并退避，正常配置继续工作。应用驻留托盘时计划继续，彻底退出时暂停，下次打开合并更新一次过期条目。停机更新不会自动启动代理。无provider且内容与保存的已验证源完全相同时，复用校验结果并更新用量/时间；新内容及provider仍经完整校验。

手动点击“更新”或保存新地址时，当前订阅的变化会自动应用；未选中订阅只更新，不切换当前配置。停机时更新下次选择，不自动启动。自动应用设置只控制定时更新；关闭后定时下载的候选可在卡片点击“立即应用”。应用可能受控重启内核并中断已有连接；内容未变化且没有待应用候选时不重启。新候选启动失败会尝试恢复旧确认会话，并在卡片提供重试应用；更新失败与既有待应用配置分别显示。代理页以代理组卡片呈现，展开后显示成员节点；url-test/fallback组由核心自动选节点，手选请操作select组。切换全局模式时，选择GLOBAL的出口；规则模式需选择规则实际引用的组。

订阅卡显示提供方上报的用量、到期时间及配置更新时间；用量采集时间与更新时间显示到分钟相同则不重复列出，不同或未知时分别显示。例如服务端返回304且没有用量信息时，更新时间会前进，采集时间仍是旧值；编辑配置也可能改变更新时间。上传或下载任一缺失时合计显示未知；总量未知不解释为无限。剩余流量不超过10%、已耗尽、七天内到期和已过期会提示；这些提示在本地更新，不额外请求订阅。提供方统计可能延迟并包含其他设备，与首页本机实时流量不同。

连接页每秒读取当前会话快照，表格固定显示目标与进程、链路、下载速率、上传速率，点击整行查看规则、累计流量、时长和原始 JSON（默认折叠）。可按主机、进程、链路和规则筛选，速率按 KiB/s 等量级显示，缺失时为短横线；筛选不会减少传输量。窄窗下表格可水平滚动。数据过大或无效会暂停更新并保留旧快照，可点击重试。关闭筛选结果只处理打开确认时捕获的连接，后续新增连接不受影响；关闭全部影响执行时的所有连接。连接结束后详情保留最后信息并禁用关闭，关闭结果区区分已关闭、已结束、失败和未知。

QuickClash 启动内核会要求识别新连接的来源进程。升级后须退出旧版并启动新版，再重新启动内核；使用 TUN 时如提示服务版本不匹配，按设置页提示更新权限服务。远程设备连接、进程已退出、系统权限限制或内核查询失败时，仍可能显示“进程不可用”；这不表示连接不可用，详情中的原始 JSON 可用于核对内核返回的 `metadata.process`。

规则页按内核实际顺序显示序号、类型、匹配内容、出口，筛选保留原序号。点击整行展开来源、RULE-SET关联提供者的数量和更新时间，命中次数受内核API限制；缺失数据标未知，不推断为0。提供者页分别标明内核运行时与所选配置快照，关闭自动应用后更新快照只保存候选并提示待应用。页面进入时读取一次，也可手动刷新；提供者整行不会触发更新，点击行尾“更新”才执行；更新逐项串行，显示本次查看期间的结果，失败保留旧值，某类读取失败不清除另一类数据。完成提示不表示远端内容一定改变，超时显示结果不确定。编辑规则点击“编辑覆盖…”，进入现有预览/确认应用事务，可选择prepend/append/replace；只读规则列表不直接热改内核。

设置页可修改代理/控制端口、查看遮蔽秘密的有效配置、打开数据目录和查看错误。默认代理端口7890、控制端口9090，均仅回环；规则模式、TUN关闭、系统代理关闭。设置中的“登录Windows时启动QuickClash”默认关闭，仅注册当前用户登录启动，无需管理员权限；“登录时隐藏到托盘”默认开启，无托盘时显示窗口。重复登录启动不弹出已有窗口。系统禁用或便携目录移动会显示实际注册状态；移动后在新目录显式开启可修复，Windows任务管理器禁用需在系统设置中重新启用。退出不删除登录启动项，停用请关闭此选项；删除便携目录前先关闭。

系统代理成功开启后保存用户意图；退出保留偏好，重开先恢复旧租约/事务，再后台运行配置并按已确认意图申请代理。明确关闭开关清除意图；外部冲突不自动覆盖。平台代理失败时保留本地转发内核、显示错误且操作不报成功。内核崩溃采用1/2/4/8/16/30秒上限退避，退出立即取消；存储只读或事务不确定时暂停自动操作。当前内核清理使用owned Job强制终止，未实现正常退出请求。

用户数据使用 Qt AppConfigLocation 下的 QuickClash 目录，内部包含 config/、data/、cache/、logs/；界面“打开数据目录”显示当前实际位置。原 P1 ui.ini 仅迁移偏好并保留原文件。不要把安装目录当数据目录。仅支持同一当前用户读取 DPAPI；复制凭据文件到另一账户不能解密。

客户端被强制终止后，Job 清理内核；系统代理需下次启动按已有租约核对并恢复。应用尚未重开时可在 Windows 设置 → 网络和 Internet → 代理中检查；不要盲目覆盖其他软件的新设置。磁盘写入失败时仍尝试依据已有租约恢复匹配的系统值，并提示无法完成日志记录。损坏/新 schema 保留文件，停止自动操作。设置页“归档损坏数据”会在确认后保留整份原件到私有recovery目录；重启后使用空仓库，再手动导入兼容配置或备份，不转换新版数据格式，也不自动启动。必须先停止内核并处理旧代理租约；租约损坏/未释放、链接路径或超量目录会阻止归档，此时打开数据目录手工检查。

归档可能含明文节点凭据，不会自动清理。归档中断时recovery_pending.json会使下次启动保持只读；先另存整个数据目录，再核对该标记指向的recovery子目录，将其中已移动的顶层目录按原路径移回，遇到同名数据须逐项保留核对，不能直接覆盖；确认恢复完整后才手工移走标记。原元数据仍需使用兼容版本读取或另存后修复。

“导出安全诊断”先展示固定字段支持包，确认后保存在logs/support_随机ID.json，最多32份。包含版本、固定设置枚举、状态、允许错误码和日志来源计数，不含日志正文、名称、地址、网址、路径、认证及连接目标；不自动上传，内核不可用/数据只读时也可使用。“检查存储清理”展示总量1GiB、临时缓存64MiB、导出日志15MiB预算，仅在超额时清理旧临时文件和导出。当前配置/历史/草稿/事务、内核缓存、备份及恢复归档受保护，可能使总量继续超额；目录超过10000文件或8GiB时需手工处理。正常空闲维护也使用此规则，不能依赖该软预算限制配置/备份总大小。

支持范围以随包metadata/config_policy.json为准，未支持字段给出具体诊断。内嵌HTTP/SOCKS5/SS/Hysteria2/Trojan/VLESS/VMess、select/url-test/fallback组、GEOIP/GEOSITE及内部fake-ip DNS已有核心加载验证；代表私有订阅仅验证单个VLESS出口，不代表所有节点可用。代理页展开组卡后可单节点/整组测速及取消，节点延迟按绿/黄/红三档着色；测速HTTPS目标在设置页配置并持久保存，与网站测试目标相互独立。自动组成员由内核策略决定。当前工作区还提供连接/规则/日志、流量/资源、受管HTTPS provider快照与RULE-SET展开、DNS缓存及本地备份等入口，已有受控runtime证据，页面完整验收和P3交付仍以任务台账为准。

规则页默认展示当前生效规则，“管理自定义规则…”用于编辑个人分流规则。仅当所选配置含受管资源时，辅助操作区显示“资源更新…”；可查看代理集合和规则集的模式、条目数、更新时间及本次查看期间的更新结果。“刷新列表”只读取状态，行尾“更新”下载所选资源；未提供条目数时显示“—”。点击“返回规则”回到生效规则，切换配置或移除全部受管资源后也自动返回。

提供者快照的单项更新只下载选中的资源，其余项使用已核对摘要的本地缓存，再重新展开并经官方校验；根据自动应用偏好决定是否重启到新快照。坏更新保留旧版本，缺失或损坏的其他资源缓存需通过完整订阅更新修复。此入口是快照重建，不等同内核提供者热更新。

订阅管理可将“提供者模式”从默认导入快照改为内核运行时；切换会重新下载和校验全部资源，应用时遵循自动应用设置。运行时保留HTTP提供者的use/RULE-SET，刷新由内核执行，无需重启；支持HTTPS、代理YAML、规则多行YAML/text，规则行为支持classical/domain/ipcidr。远端正文及跳转按冻结Mihomo解析行为处理，部分错误规则可能被忽略，应核对实际计数。interval未配置时只手动刷新，已配置的周期由内核执行；不支持本地文件、inline/MRS或自定义证书。超时提示结果未确认，先读回状态再决定是否操作。

动态成员缺少完整端点身份，只允许本次会话显式选择，不保存或自动恢复；同名成员也不作为身份相同的依据。运行时缓存由内核独占，最多32项、每项4MiB，应用在内核停止后的下次启动前清理过期缓存。历史恢复只恢复逻辑配置和导入时回退内容，后续远端内容可能不同；备份使用导入时的不可变离线回退，不包含最近热刷新的可写缓存，恢复为快照模式。

TUN入口及原生服务注册/迁移已实现，当前真实TUN异常恢复仍以验收台账为准。Geo手动更新/回退供普通和TUN模式共用，服务按同一快照验证后使用；私有运行目录物化文件可重建，无需同步两套安装资源。敏感本地备份包含明文节点凭据，须自行妥善保管。

Geo可选择直连或当前代理下载；当前代理要求内核已就绪。每次先固定官方release数据提交，再下载同一提交的两库。默认手动，可选每日/每周下载并校验，计划更新只生成“待应用”快照，不自动重启；点击“应用已下载Geo”确认后才切换。待应用快照在重开后保留。TUN模式也提供更新/回退，仍会重启当前内核并中断连接；真实TUN更新的实际验证范围以台账为准。

设置→内核更新显示实际运行版本、已选版本和本客户端兼容清单。点击“检查兼容内核”，选择直连或当前代理，再“下载或修复内核”；下载完成不会重启。点击“应用已下载内核”并确认后，先校验所选配置和Geo，再重启并确认版本/监听，失败恢复原内核和配置。可“回退内核”切回上一选择，或“使用随包内核”。当前内置清单只有官方v1.19.33，与随包相同，支持验证、修复与受管切换；不是任意上游新版本自动升级器，新版本需先随客户端更新兼容清单。跨版本兼容性以相应清单验收为准。

受管内核保存在便携core/versions目录，需可写空间和Windows系统tar.exe；ZIP及EXE均核对固定长度和SHA256。提取辅助进程短时计入客户端内存，内核运行与隔离校验进程单列。普通/TUN共用版本选择；旧服务因能力协议变化可能需要通过设置页现有入口显式更新服务。不要手工替换正在运行的EXE或向服务指定外部路径。

设置页的配置备份默认保存离线展开结果与已应用覆盖；也可选择保留原始 YAML、独立覆盖和提供者快照，此范围可能带有资源 URL。备份不包含订阅来源凭据、计划、草稿、历史、设置或 Geo 文件，尚无密码加密。解码内容最多10MiB、JSON最多16MiB，保存在数据目录的 backups 子目录。恢复先选择本地 JSON 并核对范围，再逐项经官方内核校验；整批成功后才添加为新配置。失败或取消保留旧配置，恢复不会切换当前配置、重启内核或开启 TUN。离开或隐藏设置页会取消尚未完成的恢复。兼容旧schema1，导入上限48MiB JSON/32MiB解码，配置总数最多100个。

设置中的“更新Geo数据库”从固定MetaCubeX HTTPS来源手动下载GeoIP/GeoSite，每项上限32MiB，经摘要复核和官方内核双库校验后一起应用；内核运行时会短暂重启并断开连接。两项内容均未改变时不重启。下载和校验时可取消；失败或取消保留旧快照，迟到响应不能激活新资源。“回退Geo数据库”恢复上一对资源，“使用随包Geo数据库”可显式恢复离线资源；二者也经校验和正常配置事务，保留一份上一快照。普通订阅更新不会自动下载Geo。开发源码通过受控HTTPS及真实冻结资源验证，现有dist包需重新打包后才包含此功能；受控验证不等于公网可用性或完整G3验收。

日志页按时间、级别、来源、消息分列显示，单行省略，点击行展开可选中的完整正文；级别用文字和主题色区分，不整行染色。连接、规则、提供者和日志数据按可见消费者保留：规则页切换视图释放非当前列表，离页/隐藏/销毁后最后消费者释放缓存；重进重新获取，不显示离页前迟到响应。日志最多2000条/4MiB，显示截断、丢弃及暂停缺口；暂停接收冻结缓冲，滚离尾部只停止跟随。导出先预览整个冻结缓冲，筛选仅影响页面；默认隐藏全部消息正文，可选择包含已脱敏正文。预览文本最多16KiB，文件包含完整有界快照。取消、清空或离页后旧预览失效。后台仅留最多100条/512KiB基本App诊断，不留无需求Core历史。已确认的连接关闭继续执行，未确认动作不自动执行；隐藏不停止内核转发、订阅计划或恢复，也不改变现有窗口卸载设置。现有dist包需重新打包后才包含当前功能，验收以任务台账为准。

权限服务模式下，日志关闭失败会按现有服务轮询重试，重新接收前先确认旧缓冲已清；繁忙期间也允许服务释放日志缓冲和丢弃计数，不停止核心/心跳。日志需求联验仍以任务台账为准，关闭传输与OS物理内存回落也不等同。

QuickClashService注册为自动启动，普通GUI可启动已授权服务。保留的tunDesired由应用重开后恢复，不意味着服务开机独自接管流量。只接受当前活动控制台会话；RDP及跨用户切换尚未验收。断线/重启终止旧owned核心并核对清理后再开；系统代理恢复仍由用户租约负责。

首页展开资源信息后共享采样，通常每5—6秒更新，折叠/隐藏后停止本页需求。客户端合计包括当前宿主与能够核验的权限服务；运行Mihomo和临时配置校验Mihomo分别列出，均显示专用工作集、工作集和私有提交。缺权限、服务身份无法核验或请求失败显示统计不完整及本次已知值，缺失指标显示“—”，不会把未采到的进程当作零。指标用于运行查看，采样时间可见；不能仅凭单次数字判断长期占用或字体缓存问题已解决。

订阅地址编辑时可展开可选请求头JSON，仅接受Authorization、User-Agent、Accept；更换地址不会沿用旧自定义请求头，需要时重新填写。主源最多跟随5次HTTPS跳转，跨站移除自定义来源头，不允许降级、循环或携带登录信息；不使用Cookie。整次下载含跳转/回退共20秒、累计16MiB上限。更新支持ETag/Last-Modified，304只使用摘要正确的本地原文，缓存缺失或损坏会无条件重取一次；内容不变且无待应用候选时不重启内核。管理页可保存下载路径并查看上次实际路径，新内容校验成功后才切换来源。删除当前条目先停止、恢复代理并清空选择；最后一项删除后回到未配置。代理外部冲突时设置页可明确重新开启，之后关闭恢复本次重新开启前的外部快照。

在同一订阅的管理页修改地址时，自己创建的策略组会像普通更新一样保留；订阅本身提供的策略组则以新内容为准。如果新内容缺少自建组所需的父组或提供者，或存在组名冲突，更新会失败并保留旧来源及自建组。删除订阅会同时移除属于它的自建组，手动回退历史版本则恢复该版本的组定义。

订阅管理提供原始YAML和配置覆盖项两个编辑入口。原文保留注释，覆盖项单独保存且随订阅更新保留。例如在覆盖编辑器输入以下JSON，在原规则前加入一条直连规则并设置日志等级：

    {"set":{"log-level":"warning"},"rules":{"mode":"prepend","items":["DOMAIN,example.invalid,DIRECT"]}}

set合并对象、替换数组；remove为要删除的根字段数组；rules支持prepend、append、replace。监听端口、控制器、TUN和provider引用由应用管理，不能通过覆盖项修改。编辑上限1MiB，超过时使用文件导入；覆盖JSON另有256KiB上限。原文和草稿可能含节点凭据，存于限制访问的本地目录，勿随意分享。

修改后先点击“校验并预览”，比较当前配置和草稿的脱敏有效内容，再确认保存应用或另存本地副本。草稿延迟自动保存，也可显式保存；隐藏前尝试保存，强杀可能丢失最后尚未落盘的编辑。订阅更新与草稿冲突时，只能比较、另存副本或确认加载最新版本。管理页可选择保留的历史版本回退，先校验再应用；回退保留当前下载来源及计划，不重新下载远端资源。运行中的应用可能重启并中断连接，失败时保留草稿/候选并尝试恢复旧会话；以当前运行状态和待应用提示为准。
