重复规则集仍保留顺序，但整次展开累计扫描超过128MiB或200000事件会拒绝候选；异常显式YAML标签拒绝。新限制尚待产品验证。

窗口最小360×480逻辑像素，可缩为手机比例竖屏。宽度小于600时，底部只显示仪表盘、代理和设置；订阅可从仪表盘管理，其他页面从设置的“更多页面”进入。缩放不切换当前页面，也不重新启动内核。

界面语言自动跟随系统首选语言，支持英文、中文（当前统一简体词表）；无匹配使用英文。更改系统语言后重新启动QuickClash。无需联网下载语言包。

运行 bin/quickclash.exe，内核来自随包 core/mihomo.exe，版本和摘要见 metadata/release_matrix.json。启动无需开发 Qt PATH，无自动下载内核；不要移动其中单个 exe。

Geo数据位于geo/，须与整个目录一起保留。程序在导入和启动时核对固定摘要，资源缺失或损坏会阻止相关配置，不会联网自动补下载。

1. 在订阅页导入本地Mihomo YAML，或粘贴标准HTTPS订阅地址。程序自动请求Clash/Mihomo格式并识别内容；无需手工添加格式参数。Base64/分享链接尚不转换，URL适配不代表配置中所有协议均已接入。订阅地址以当前用户 DPAPI 加密保存；当前版本拒绝重定向，请提供最终 HTTPS 地址。
2. 首份有效配置自动选中，后台自动运行随包Mihomo；之后点击订阅卡片切换配置，代理页随之显示该订阅的分组。导入成功与内核就绪分别显示；首次不会自动开启系统代理或TUN。无需管理内核列表或手动启动。
3. 代理页按订阅原顺序显示分组，“正在查看分组”只控制显示哪些成员；选择select组成员才改变该组的出口。顶部显示默认出口组到最终节点，首页提供精简提示。规则模式依据MATCH默认策略，全局依据GLOBAL，直连显示DIRECT；不同规则和已有连接可能使用其他节点。自动组由Mihomo选择成员，可见时约5秒刷新当前值。首页切换规则/全局/直连模式；运行中切换配置、模式或端口会受控重启，失败尝试恢复原确认版本。
4. 首页“系统代理”开启当前用户 WinINet LAN 的 HTTP/HTTPS 代理；客户端就绪及节点恢复后才写入。它不覆盖 WinHTTP、RAS、其他用户或应用自己的代理配置。
5. 测试页可填写最多8个HTTPS网站，每行一个；选择当前代理、直连或系统默认路径。请求串行执行GET，每项12秒/64KiB上限，不跟随重定向；当前代理失败不回退直连。规则可能选择DIRECT，因此网站可达不代表指定远端节点转发成功。
6. 关闭窗口可保留托盘和内核；关闭系统代理仅释放代理租约，后台内核继续提供本地转发。退出才清理本应用会话/Job并恢复仍拥有的设置。发现其他程序更改代理时保留外部值并提示冲突。

首页“连接与系统”分别显示QuickClash客户端和Mihomo内核的内存。专用工作集是当前驻留且不共享的物理内存；工作集包含共享驻留页；私有提交是进程承诺使用的私有内存，不能当作当前物理占用。三项均使用十进制MB；客户端包含运行中的必要辅助服务，内核单列，不能相加后判断客户端100MB目标。缺失数据以破折号显示。

### 开发者可选：只读附着内存短测

在仓库根目录使用PowerShell 7.2+运行[附着脚本](../../bench/attach_memory_windows.ps1)。通过任务管理器确认客户端、必要辅助服务及内核PID后，分别传入客户端列表与内核列表；输出目录必须尚不存在。例如本机确认的客户端PID为1234、辅助服务2345、内核3456时：

    & ./bench/attach_memory_windows.ps1 -ClientPid @(1234,2345) -CorePid 3456 -OutputDirectory .local/memory_user_update -Seconds 10

上述数组参数示例在PowerShell 7.2+交互终端直接调用脚本；不要将示例PID照搬为真实目标。脚本只查询，不启动/退出/裁剪进程，不读取命令行或订阅；普通权限失败即报告未知/失败，不需提升权限。可在采样期间自行正常操作订阅更新。输出每PID三指标、角色和采样轮次，不自动证明来源版本或进程组完整；比较100MB需按采样轮次将所有必要客户端/服务相加，内核另列，不相加各PID不同轮的峰值。内核更新重启后旧PID样本不完整，需重新确认PID再采样；新代码未构建时，旧实例读数不能当新代码验收。

新添加的订阅默认每6小时自动更新，选中条目有变化时自动应用；在订阅条目选择手动/每小时/6小时/12小时/每天，以及“选中时自动应用更新”。旧条目保持原来的手动策略，需要自行开启。更新时间以本地时间显示；失败有状态并退避，正常配置继续工作。应用驻留托盘时计划继续，彻底退出时暂停，下次打开合并更新一次过期条目。停机更新不会自动启动代理。无provider且内容与保存的已验证源完全相同时，复用校验结果并更新用量/时间；新内容及provider仍经完整校验。

自动应用会受控重启内核，已有连接会中断；如不希望使用中切换，可关闭自动应用，等待方便时点击“使用”。下载未变化则不重启。通过校验的新候选若启动失败，会尝试恢复旧确认会话，并显示更新失败/等待应用。代理页可按名称筛选节点；url-test/fallback组由核心自动选节点，手选请操作select组。切换全局模式时，选择GLOBAL的出口；规则模式需选择规则实际引用的组。

设置页可修改代理/控制端口、查看遮蔽秘密的有效配置、打开数据目录和查看错误。默认代理端口7890、控制端口9090，均仅回环；规则模式、TUN关闭、系统代理关闭。有效配置在后台运行，应用开机启动注册不包含在当前行为中。

系统代理成功开启后保存用户意图；退出保留偏好，重开先恢复旧租约/事务，再后台运行配置并按已确认意图申请代理。明确关闭开关清除意图；外部冲突不自动覆盖。平台代理失败时保留本地转发内核、显示错误且操作不报成功。内核崩溃采用1/2/4/8/16/30秒上限退避，退出立即取消；存储只读或事务不确定时暂停自动操作。当前内核清理使用owned Job强制终止，未实现正常退出请求。

用户数据使用 Qt AppConfigLocation 下的 QuickClash 目录，内部包含 config/、data/、cache/、logs/；界面“打开数据目录”显示当前实际位置。原 P1 ui.ini 仅迁移偏好并保留原文件。不要把安装目录当数据目录。仅支持同一当前用户读取 DPAPI；复制凭据文件到另一账户不能解密。

客户端被强制终止后，Job 清理内核；系统代理需下次启动按已有租约核对并恢复。应用尚未重开时可在 Windows 设置 → 网络和 Internet → 代理中检查；不要盲目覆盖其他软件的新设置。磁盘写入失败时仍尝试依据已有租约恢复匹配的系统值，并提示无法完成日志记录。损坏/新 schema 保留文件，停止自动操作，可备份后手工修复。

支持范围以随包metadata/config_policy.json为准，未支持字段给出具体诊断。内嵌HTTP/SOCKS5/SS/Hysteria2/Trojan/VLESS/VMess、select/url-test/fallback组、GEOIP/GEOSITE及内部fake-ip DNS已有核心加载验证；代表私有订阅仅验证单个VLESS出口，不代表所有节点可用。代理页可筛选、单节点/批量测速及取消；自动组成员由内核策略决定。当前工作区还提供连接/规则/日志、流量/资源、受管HTTPS provider快照与RULE-SET展开、DNS缓存及本地备份等入口，已有受控runtime证据，页面完整验收和P3交付仍以任务台账为准。

TUN入口及Windows服务安装脚本已实现，当前包尚未完成真实服务安装/TUN转发验收，不能视作已可日常使用。普通系统代理路径无需安装服务；本轮没有修改系统DNS、安装服务或启用TUN。Geo随包校验已验证；设置中的手动Geo更新/回退属于待完成正向联网核对的P3能力。敏感本地备份包含明文节点凭据，须在界面确认后保存并自行妥善保管。

本轮源码中的手动Geo更新改为有界流式暂存及摘要复核后原子提交，每个资源上限32MiB，普通配置写入仍16MiB；失败/取消保留旧快照，迟到响应不能激活新资源。这不是普通订阅每次更新的必经步骤。该源码尚未构建或进行GUI/联网/内存产品验收，现有旧包不自动获得此行为。

本轮P1-B源码还按可见消费者保留连接、规则、提供者和日志数据：规则页切换页签释放非当前列表，离页/隐藏/销毁后最后消费者释放缓存；重进重新获取，不显示离页前迟到响应。暂停日志只停止该页实时接收，仍可见的冻结缓冲和待恢复值有界；离开或隐藏即清，恢复不保证补齐缺口。后台仅留最多100条基本App诊断，不留无需求的Core页面历史；离页导出因此不是完整Core历史。已确认的连接关闭继续执行，未确认动作不自动执行；隐藏不停止内核转发、订阅计划或恢复，也不改变现有窗口卸载设置。上述为未构建源码行为，GUI/并发/内存验证NotRun，不表示现有旧包已支持或产生具体MB收益。

权限服务模式下，日志关闭失败会按现有服务轮询重试，重新接收前先确认旧缓冲已清；繁忙期间也允许服务释放日志缓冲和丢弃计数，不停止核心/心跳。该路径仅完成源码和测试源，未安装或启动服务验证，关闭传输与OS物理内存回落也不等同。

该包用于本机开发验证。未签名，尚未在干净普通用户环境验收；公网发行前还需确定项目许可及 Qt/Mihomo 完整对应源码提供方案，现有许可证和上游链接不能代替这些义务。

订阅条目支持“校验并更换来源”，可选请求头 JSON 仅接受 Authorization、User-Agent、Accept，不跟随重定向。新内容校验成功后才切换来源记录，是否应用遵从该条目自动应用开关；关闭时需点击“使用”。地址和头均以DPAPI保存。删除当前条目会先停止、恢复代理并清空选择；最后一项删除后回到未配置。代理发生外部冲突时，设置页提供明确的重新开启按钮，之后关闭恢复的是本次重新开启前的外部快照。
