# UI 参考冻结记录

P0-05，2026-10-23。唯一布局证据为用户截图 UI-REF-20261023-01，720×455，SHA-256 66434ed9cf6bcb8a04af5ed15f88d93e8f30fa500c22a0ac927479c275d230c2。原始来源/权限见 [记录](README.md)；[图片](flclash-dashboard-user-reference.png) 的像素不是窗口逻辑尺寸。

本阶段不复用 FlClash 源码/字体/图标，不进行版本性能比较，因此不虚构上游 tag/commit。若后续要复用源码或宣称和某版本比较，在引入前补充对应 tag/commit、许可及运行环境。P1 的视觉冻结以用户图片及 [17](../design/17-FlClash界面参考与QtQuick落地.md) 自有 token 为准，代码版本未知不阻塞自主 QML 实现。

| 稳定模块 ID | 页面/独立内容边界 | MVP 与空/进行中/错误行为 |
|---|---|---|
| home | 首页组合订阅/组/测试摘要；不创建全部页面 | 未配置→导入入口；启停阶段真实；未知值不显示为 0 |
| proxies | 独立代理页，允许组选择摘要嵌入 home | 内核未 Ready 说明不可操作；选择 pending→读回；失败保留旧值 |
| subscriptions | 独立页及当前来源摘要 | 两来源/更新/选择/删除；下载不是运行成功；迟到结果失效 |
| connections | 完整连接页，轻量入口可嵌入 | P2 未交付完整列表时明确说明；P3 按需虚拟列表 |
| rules | 独立只读规则页 | P2 能执行规则但不冒充完整查看器已完成 |
| logs | 独立有界日志，最近错误摘要 | P2 内核不可用时仍有错误入口；P3 完整查看 |
| tests | 独立网站测试及单目标摘要 | 手动触发，标路径/时间；P2 无直连假成功，IP 未启用则隐藏 |
| settings | 独立设置分类/修复 | P2 端口/凭据/关闭行为；TUN 未支持应禁用并有原因 |

桌面左侧八模块投影与右侧页分离，首页嵌入摘要只引用模块公开工厂和独立 instanceKey。未来移动底栏精选或更多入口，路由和 capability 检查仍有效；当前不实现移动壳。

采用截图的侧栏、状态宽块＋两流量块、控制条及摘要分区；调整导航为八模块、保留本平台窗口按钮。网络模式、系统代理、TUN 独立确认；IP 质量/请求数/DNS 数无来源即隐藏，不复刻图片数据。

P1 待验证样本：1000×700/1280×800/720×560、大字体与高 DPI、长组名、空/加载/失败/运行、深色/浅色、键盘与滚动、模块独立页/嵌入、隐藏需求释放。断点和最小窗口仍是候选，P0 空壳的尺寸不是最终支持声明。两主题随包、跟随系统首帧与主题切换状态保持在 P1 实现。
